# ② 公開網站

[開啟網站](https://dimension-ai-agent.github.io/ai-marketing-website-public/) · [私人素材提交入口（限團隊）](https://github.com/Dimension-AI-Agent/ai-marketing-website)

本 repository 放網站前端及已核准公開的內容；任何人都能查看檔案與提交紀錄。

團隊從私人表單交件，Mark 確認後，由私人專案的發布程式複製附件並更新這裡的素材清單。GitHub Pages 會發布到同一個網址。系統只有確認公開網站出現相同版本，才回報已上站。

**自動發布仍需在私人專案完成授權設定及真實附件驗證。** 詳情見私人專案的 SETUP.md。

對外摘要、正文、公開連結和已核准附件可以出現在網站；原始來源與內部備註不會由發布程式帶入。圖片、音訊、影片提供預覽及檔案連結，其他文件提供開啟／下載。

首頁呈現三層地圖與互動引導；搜尋與分類集中在獨立的「所有文章」View（`#all-articles`）。分類直接讀取 `data/site.json`，包含「IT 基礎架構與選型」「企業 AI 與 Agent 實務」「資安與營運韌性」「訊達成功案例」四個主題、16 個子題。桌機使用可展開的側欄、手機使用主題與子題選單；零篇子題保留設定，先不顯示篩選入口。可在所選分類內搜尋，完整顯示相符文章；沒有內容時顯示空狀態。HPE 專區與訊達成功案例專區維持獨立 View。

文章直達連結使用 `?article=material-編號`；從所有文章進入閱讀後，返回連結保留主題、子題、關鍵字與標籤。點擊輔助標籤以 `?tag=標籤#all-articles` 精確查找跨分類的同標籤文章；沒有標籤的舊文章仍可正常閱讀。舊版 `#material-編號` 仍可開啟同一篇文章，`#home-search`、`#articles` 及 `?q=...`／`?filter=topic:...` 會轉到所有文章。

每篇文章有一個依所屬子題提供的下一步檢查動作。「接著想了解什麼？」只取用 `data/site.json` 中已編輯確認的配對，沒有合適文章時不補上其他文章。另設「相關文章」，以共同標籤與相同主要子題的固定規則產生，說明關聯原因，最多三篇，不呼叫 AI API。`data/article-views.json` 保留供未來接入可信點閱資料，目前首頁不顯示熱門或全部文章清單。資料格式見 [發布說明](PUBLISHING.md)。

網站設計或程式變更走 Pull Request；經 Mark 確認的素材更新由發布程式直接提交 main。參閱 [發布說明](PUBLISHING.md)。

## 互動引導的文章推薦資料

`data/guide-recommendations.json` 保存互動引導 10 種結果的說明及已審閱文章推薦。每個結果可連 0–2 篇文章；同一篇可以對應多種結果。文章以 `material-編號` 指向 `data/materials.json`，並記錄核准版本 `revision`。網站呈現時仍應確認文章存在且狀態為「已核准」。

本分支的首頁 Demo 已改為五題問卷，順序是工作、目標、使用階段、觀察或準備狀態、判別線索。後兩題依答案分支，每條路徑都回答五題。原有 `results` 十組正式配對資料保留；Demo 改用新增的 `assessment` 文章候選池，標記為 `local-demo`，尚非正式配對核准。

結果分開呈現初步判讀、支持依據、其他可能解釋、最小驗證行動與對應文章。判讀由可檢查的固定規則產生，不呼叫 AI API、不產生成熟度或效益分數。回答紀錄可展開並從任一題修改；該題與後續答案會清除，重新走適用分支。選項代碼以 `sessionStorage` 暫存於同一瀏覽器分頁，從文章返回或重新載入仍可查看結果；重新開始會清除。不傳送回答、不新增分析事件；瀏覽器禁止暫存時仍可在當頁完成問卷。

每個結果會檢查候選文章是否存在、已核准、非 HPE 專區且版本吻合，才顯示最多兩篇連結。`browseTopic` 提供既有分類文章與篇數入口；分類不存在或沒有核准文章時改為所有文章。推薦資料讀取失敗仍可完成問卷、查看判讀與瀏覽分類。問卷規則與 Demo 驗收方式見 [五題問卷說明](docs/guide-assessment.md)。

私人素材專案負責在每次發布後及每週檢查已核准文章全文，將 AI 的候選推薦放在私人 Issue 供 Mark 審閱。確認後以本 repository 的 `codex/` 分支和 Pull Request 更新此檔。這份資料不會讓 AI 在訪客瀏覽時即時決定文章。

## 三層 3D 本機原型

首頁保留三層總覽，選擇樓層後可探索各自的 3D 場景。每層有三個物件，支援縮放、有限旋轉、選取簡介與已核准文章；從場景開啟的文章可返回該樓層。模型為概念示意，不代表實際設備型號或必備建置規模。

在 repository 目錄執行 `npm run preview`，開啟 `http://localhost:8745/`。伺服器只綁定本機；可使用 `PORT` 環境變數指定其他連接埠。原型與維護方式見 [3D 原型說明](docs/3d-prototype.md)。

驗證命令：`npm test`。Three.js 固定為 `0.186.1`，瀏覽器讀取已納入版本控制的 `vendor/three/`，不依賴執行建置或外部 CDN。更新套件時執行 `npm ci --ignore-scripts` 與 `npm run vendor:three`，再檢查差異及測試；不要手動改寫 vendor 檔案。僅進入樓層時才載入 Three.js。
