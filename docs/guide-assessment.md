# 五題現況判讀 Demo

此分支只供本機評估，未部署。判讀是固定規則產生的待驗證解釋，不是經客戶研究驗證的診斷工具。正式採用前需確認題目、判讀文案與文章配對。

## 問卷與規則

題目、選項與純函式 `guideQuestion`、`guideReport` 位於 `guide.js`。每條路徑固定五題：

1. 工作：查找文件、製作文件或報表、回覆客戶、跨系統處理資料、其他、還沒決定。
2. 目標：縮短完成時間、減少錯誤重做、縮短等待、減少重複操作交接、尚未決定。
3. 階段：未試過、個別測試、團隊試用、日常使用、不清楚。
4. 未試過者選準備狀態；其他人選最近一次觀察，不知道過程可明確回答不清楚。
5. 依前述回答選擇能區分可能解釋的證據。

第五題依下列順序決定，不使用加總分數：

| 第四題或條件 | 第五題 | 判讀重點 |
| --- | --- | --- |
| 未試用：未選工作 | 誰能提供實例 | 將方向縮成一件可觀察工作 |
| 未試用：沒有範例 | 範例位置或是否留下 | 區分未整理、分散、未留存及不清楚 |
| 未試用：未定標準 | 誰判斷結果 | 區分驗收標準與權責資訊缺口 |
| 未試用：範例與預期俱備 | 測試使用許可 | 區分可試、待完成條件、禁止與未知 |
| 未試用：準備不清楚 | 可確認的窗口 | 先補足資訊，不推定能力不足 |
| 可直接採用 | 成效比較證據 | 可用不等於目標已改善；有紀錄不等於有成效 |
| 工作未完成 | 最後停在哪一步 | 只定位阻礙，列出需核對的原因 |
| 未觀察過程 | 能取得的過程資料 | 區分完整、部分、口述、找不到及不清楚 |
| 省時目標＋修改／核對／搬移 | 計入人工後的總時間 | 較短、差不多、較長、感受、未比較分別處理 |
| 其他目標＋修改內容 | 修改原因 | 區分來源、處理、標準與資訊不足 |
| 其他目標＋搬移整理 | 後續操作規則 | 區分固定格式、跨系統、人工判斷及混合 |
| 其他目標＋核對核准 | 核對過程或等待位置 | 區分正常核對、排隊、決策者、補資料與核對本身 |

第一題決定驗證工作的單位；第二題決定觀察指標；第三題界定準備與實際使用，並限制解釋範圍；後兩題共同決定主要判讀。工作未選定或使用階段未知時，題目與摘要會明確保留這個限制。

結果依序為：初步判讀、現況範圍、解釋、兩項支持依據、另一種可能解釋、二至三項驗證行動、對應文章。判讀限定於回答所描述的經驗，不延伸推論企業整體表現。

例如「查找文件／省時／團隊試用／人工核對」會追問完整工時：

- 較短：目前紀錄支持淨省時，再核對品質與案件可比性。
- 差不多：先檢查前段節省是否被後段處理抵銷，也可能品質或難度不同。
- 較長：定位增加時間的一段，保留學習期及案件差異的解釋。
- 只有感受或尚未比較：先記錄完整工時，不宣稱已有效或無效。

## 文章資料與邊界

`data/guide-recommendations.json` 的 `assessment` 區段是本機 Demo 候選配對。文章本文在規劃階段已核對，但不代表發布流程中的人工配對核准。原有 `results` 與 `catalogHash` 保留，不更新投稿 Issue、文章本文、正式分類標籤或 `site.json` 的編輯配對。

候選文章：26（資料安全）、27（內部系統整合）、30（導入階段）、31（效益面向）、34（資料存取）、35（任務評估）、41（工作流程）、44（PoC）、46（人工接手）、50（權責）、53（訊達報價流程）。每筆保留本文核對時的 revision，版本變動即隱藏該連結，不自動改成新版本。頁面仍有既有分類閱讀入口。

問卷不新增網路請求或追蹤事件。五個選項代碼只存在當頁與瀏覽器 `sessionStorage` 的 `dimension-guide-demo-v1`，不送出。從文章返回或重新載入可恢復問卷／結果，重新開始會清除。載入時重新驗證完整分支；格式錯誤、過時或不適用答案會回到第一題。暫存不可用時，當頁互動仍可完成。點文章沿用既有閱讀路由；沒有 AI API、後端服務或新依賴。

## 驗證

執行 `npm test`，或以 Node 執行 `node --test tests/guide-report.test.cjs` 驗證問卷。

- 遍歷所有有效選項組合，確認五題、非空判讀、行動數、分類及文章版本。
- 檢查相反證據得到不同判讀、未知與明確缺少不混用、資料禁止與未確認分開。
- 六種代表情境：尚未開始、品質問題、人工搬移、權限未確認、效益未確認、資訊不足。
- 修改任一題清除其後答案，重新計算第四、五題；不接受不適用的選項。
- 核對正常且沒有等待時不推定瓶頸；不知道許可狀態不等於團隊尚未確認。
- 同分頁從文章返回保留答案；重新開始清除暫存，損毀資料或停用暫存不阻斷問卷。
- 檢查文章的核准、版本、HPE 隔離、缺資料回退與 HTML 轉義。
- 整合測試保留首頁、分類、文章、編輯推薦及 3D 場景路徑。

預覽依 README 的本機啟動方式。人工檢查桌機與手機：完成五題、展開回答、修改第二或第三題、重新回答、閱讀結果文章、鍵盤焦點和水平溢出。
