# 五題現況判斷

網站維護者於 2026-10-19 確認採用新版五題問卷、判斷文案與文章配對。新版取代 2026-10-14 的版本：舊版問的是驗證材料是否齊備，報告多半只能請填答者補資料；新版改問工作卡在哪、需要的資料在哪，報告給出一個明確判斷和這週可以做的第一步。判斷是固定規則產生的建議，不是經客戶研究驗證的診斷工具。

## 問卷

題目、選項、文案與純函式 `guideQuestion`、`guideReport` 位於 `guide.js`。每條路徑固定五題，不依答案跳到其他題組：

1. 工作類型：查找文件、製作文件或報表、回覆客戶、跨系統處理資料、還沒確定。
2. 卡點：依第 1 題出題，每種工作類型 4 個選項。「還沒確定」改問團隊最常見的情況，前四項對應到四種工作類型的代表卡點，「都不太像」進入通用結果。
3. 起點條件：依工作類型出題，問需要的資料或答案在哪裡。每個選項對應齊備、分散、困難或未知。
4. 頻率：每天好幾件、每週幾件、每月幾次但份量大、不固定。
5. AI 使用階段：還沒開始、個人使用通用工具、團隊有導入工具、已接上內部資料或系統、不清楚。

填答者身分無法控管，題目只問主管和執行者都看得到的症狀，不問紀錄或細節。「不清楚／說不上來」只保留在第 3 題的查找文件、跨系統處理資料、通用結果，以及第 5 題；選了也會得到一個可以直接去問的問題。

## 報告組成

| 區塊 | 決定的題目 |
| --- | --- |
| 判斷（標題）、為什麼會這樣、怎樣算有進展 | 第 1、2 題（16 種，另有 1 種通用結果） |
| AI 可以怎麼幫 | 第 1、2 題，再接一句依第 4 題頻率調整的說明 |
| 你的起點 | 第 3 題 |
| 這週可以做的一件事 | 第 1、2 題；第 3 題不是齊備時先加一個前置步驟，前置步驟與本週行動重複時只顯示本週行動 |
| 依你們目前的階段 | 第 5 題 |
| 延伸閱讀 | 判斷的第一篇、階段的一篇、判斷的第二篇，去除重複後最多 3 篇 |
| 真人諮詢 | 符合下列任一條件時顯示 |

真人諮詢的條件：查找文件｜要申請權限；回覆客戶｜查客戶的訂單、合約或帳務；回覆客戶｜答案在系統裡要逐筆查；跨系統處理資料｜只能在系統畫面上操作；已接上內部資料或系統；通用結果。聯絡方式為 02-2501-5568 分機 2591、2586，服務時間 10:00–18:00。

文案不寫百分比或成效承諾。提到的案例只引用已核准文章：訊達報價流程（material-53）與智慧維修 AI Agent（material-13）。

## 擴充

新增一種工作類型時，在 `guidedQuestions.work` 加一個選項，在 `guidedQuestions.pain` 與 `guidedQuestions.source` 各加一題，在 `guideFindings` 補 4 種判斷、在 `guideSources` 補 4 種起點；視需要更新「還沒確定」的對應選項。第 4、5 題與報告結構不用改。

## 文章資料與邊界

`data/guide-recommendations.json` 的 `assessment` 區段保存文章配對，狀態為 `approved`。後續配對變更仍經網站 PR 審閱。原有 `results` 與 `catalogHash` 保留。

配對文章：13（智慧維修 Agent）、26（資料安全）、27（內部系統整合）、28（不一定需要大型語言模型）、29（資料是否外流）、30（導入階段）、34（資料存取）、35（任務評估）、41（工作流程）、44（PoC）、45（PoC 到上線）、46（人工接手）、50（權責）、53（訊達報價流程）。material-31 保留在資料中，新版問卷未使用。每筆保留本文核對時的 revision，版本變動即隱藏該連結，不自動改成新版本。

問卷不新增網路請求或追蹤事件。五個選項代碼只存在當頁與瀏覽器 `sessionStorage` 的 `dimension-guide-v2`，不送出；舊版的 `dimension-guide-demo-v1` 不再讀取。從文章返回或重新載入可恢復問卷與結果，重新開始會清除。載入時重新驗證完整分支；格式錯誤、過時或不適用的答案會回到第一題。暫存不可用時，當頁互動仍可完成。

## 驗證

執行 `npm test`，或以 Node 執行 `node --test tests/guide-report.test.cjs` 驗證問卷。

- 遍歷全部 1,680 條路徑，確認五題、報告欄位完整、17 種判斷都可到達、文章版本與核准狀態，且文案不含百分比或承諾字眼。
- 工作類型會改變第 2、3 題；「還沒確定」對應的情況與直接選該工作類型得到相同判斷；四種頻率給出不同說明。
- 設計稿的三份範例報告逐字核對標題、行動、文章與是否顯示真人諮詢。
- 真人諮詢只在約定條件出現；前置步驟只在需要時加入，且不與本週行動重複。
- 修改任一題清除其後答案並換成適用的後續題目；不接受不適用的選項。
- 同分頁從文章返回保留答案；重新開始清除暫存；舊版暫存、損毀資料或停用暫存不阻斷問卷。
- 文章的核准、版本、HPE 隔離、缺資料回退與 HTML 轉義。

預覽依 README 的本機啟動方式。人工檢查桌機與手機：完成五題、展開回答、修改第二或第三題、閱讀結果文章、真人諮詢區塊、鍵盤焦點和水平溢出。
